# Event Planner — User Manual / 使用手册

Plan an event by the hour and stay inside your budget.
按小时预订供应商，把活动办在预算之内。

---

## 1. What it does / 产品做什么

**EN** — Instead of booking full-day vendor packages, you assemble an event à la carte: a venue, a photographer for 3 hours, a DJ for 4, a makeup artist, a chef. Every price is hourly, so the total moves with the hours you pick.

**中** — 不必按整天打包预订。你可以按需拼装：一个场地、3 小时摄影、4 小时 DJ、一位化妆师、一位主厨。所有报价按小时计算，总价随小时数实时变化。

---

## 2. Screens / 界面

| Screen 界面 | What you do 用途 |
|---|---|
| **Plan** 计划 | Set event type, date, city, guests, budget. Pick a category. 设置类型、日期、城市、人数、预算，选择品类。 |
| **Browse** 浏览 | Compare vendors in that category by hourly rate. 按小时费率比较同类供应商。 |
| **Vendor** 详情 | Read bio and reviews, set hours, pick a start time, see the estimate. 查看介绍与评价，设定小时数与时段，看到估价。 |
| **My event** 我的活动 | All selections, total vs budget, and what's still missing. 已选清单、总价与预算对比、缺失提示。 |
| **Sent** 已发送 | Confirmation that requests went to the vendors. 确认请求已发送给供应商。 |

---

## 3. Step by step / 操作步骤

1. **Set your frame.** On Plan, choose Wedding / Birthday / Anniversary / Graduation, then date, city, guest count and budget.
   **设定框架。** 在 Plan 页选择活动类型，填写日期、城市、人数与预算。
2. **Open a category.** Five verticals: Venue, Photographer, Music DJ, Makeup Artist, Food Chef. Each shows its lowest hourly rate.
   **打开品类。** 五个模块：场地、摄影、DJ、化妆、主厨；每项显示最低小时价。
3. **Compare.** The list shows the hourly rate and a 3-hour reference price.
   **比价。** 列表显示小时费率与 3 小时参考价。
4. **Choose hours.** On the vendor page use − / + to set hours. The estimate updates immediately. Pick a start time.
   **选择小时数。** 在详情页用 − / + 调整小时数，估价即时更新，并选择开始时段。
5. **Add to event.** One vendor per category — adding a second replaces the first.
   **加入活动。** 每个品类只保留一位供应商，再次添加会替换。
6. **Check the budget.** My event shows total, a progress bar, and either money left or the amount over budget (shown in red).
   **核对预算。** 我的活动页显示总价、进度条，以及剩余额度或超支金额（红色）。
7. **Send requests.** One tap sends enquiries to every selected vendor.
   **发送请求。** 一键向所有已选供应商发送询价。

---

## 4. Good to know / 注意事项

- **Prices are estimates** = hourly rate × hours. Vendors confirm the final amount.
  **报价为估算**，等于小时费率 × 小时数，最终金额由供应商确认。
- **Over budget is allowed** — the app warns, it does not block.
  **允许超预算**，系统只提示，不阻止。
- **Remove anything** from My event to free up budget.
  在我的活动页可**移除任意项**以释放预算。
- **Portfolio images are placeholders** in this build.
  当前版本的作品图为**占位图**。

---

## 5. Current limits / 当前限制

No accounts, no payment, no vendor portal. Selections live in the browser session only; refreshing starts a new plan.
暂无账户、支付与供应商后台。选择仅存在于当前浏览器会话，刷新后重新开始。
